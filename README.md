# Project Control — Football Stadium Construction

A project control and planning project focused on planning the construction of a 60,000-seat football stadium using Microsoft Project.

## Overview

The project applies project management and scheduling concepts to a large-scale construction scenario. It covers project scope definition, work breakdown, activity scheduling, dependencies, resources, and project control.

## Key Areas

- Project planning and scheduling
- Work Breakdown Structure (WBS)
- Activity sequencing and dependencies
- Resource planning
- Project duration and milestones
- Project monitoring and control
- Microsoft Project (MSP)
